# 今日学习笔记

1. **Git 协作**：分支隔离 + PR 审批 = 团队高效协作。
2. **深度学习本质**：自动提取特征，端到端解决问题。

- 自动特征提取：DL 的核心。
- M-P 模型：神经网络的数学鼻祖。
- torch.nn.Linear：搭建网络的基本积木。

3. **神经元灵魂公式**：$y = f(wx + b)$。

4. **前向与反向**：数据向前猜答案（Forward），误差向后改权重（Backward），隐藏层：深度学习之所以"深"的原因。

5. **三大法宝**：

- **激活函数**：ReLU (掰弯直线，赋予灵性)。
- **损失函数**：MSE/CrossEntropy (量化错误，明确目标)。
- **优化器**：Adam (自动驾驶，寻找最优)。

6. **底层载体**：Tensor (砖块)，.to(device) (上天入地)。

- Tensor 是数据的容器。
- `.to(device)` 是提速的密码。
- 维度匹配是搭建网络的地基。
