# 一、为什么不用numpy而是用tensor

PyTorch 选择张量（Tensor）而非 NumPy 的 ndarray 作为核心数据结构，根本原因在于两者的**设计目标不同**：NumPy 是为通用科学计算而生的数组库，而 PyTorch 是为深度学习量身打造的框架。具体来说，有以下关键差异：

------

### 1. 自动微分（Autograd）

- **PyTorch Tensor**：支持自动微分。通过 `requires_grad=True` 可以记录张量上的所有操作，构建动态计算图，并在反向传播时自动计算梯度。这是训练神经网络的基础。
- **NumPy ndarray**：没有自动微分功能，无法追踪操作历史或计算梯度。即使能通过数值近似求导，效率低且无法与优化器无缝配合。

### 2. GPU 加速

- **PyTorch Tensor**：可以轻松地在 CPU 和 GPU 之间移动（`.cuda()` / `.to(device)`），并利用 CUDA 进行大规模并行计算。现代深度学习离不开 GPU 加速。
- **NumPy ndarray**：仅支持 CPU 计算，无法直接利用 GPU 硬件加速。

### 3. 动态计算图

- **PyTorch Tensor**：采用动态图（define-by-run）机制，计算图在每次前向传播时动态构建，灵活支持控制流（如循环、条件分支），适合处理变长序列、动态网络结构等。
- **NumPy ndarray**：仅作为静态数组存在，没有计算图概念，无法表示复杂的网络结构并自动求导。

### 4. 与深度学习生态的深度集成

- **PyTorch Tensor**：作为 PyTorch 框架的底层数据单元，与 `torch.nn` 模块、优化器、损失函数等无缝对接。模型的参数、输入、输出都是张量，形成统一的编程范式。
- **NumPy ndarray**：没有与深度学习组件集成的设计，若强行使用 NumPy 实现神经网络，需要手动实现反向传播和参数更新，代码冗长且效率低。

### 5. 性能优化

- **PyTorch Tensor**：核心操作（如卷积、矩阵乘法）基于 C++（ATen）和 cuDNN、MKL 等高性能库实现，针对深度学习常见运算进行了极致优化。
- **NumPy ndarray**：虽然也使用 C 语言实现，但其优化目标是通用数值计算，缺乏对深度学习中特定操作（如卷积、批归一化、激活函数）的专门优化。

------

### 补充说明

PyTorch 张量与 NumPy 数组可以**高效互转**（`torch.from_numpy()` / `.numpy()`），因此在实际开发中，两者并不对立。在数据预处理等阶段，往往先使用 NumPy 处理数据，再转换为 PyTorch 张量送入模型。

------

### 总结

PyTorch 使用张量而非 NumPy ndarray，是因为张量天然支持自动微分、GPU 加速、动态图构建，并与深度学习框架深度集成。这些特性是训练现代神经网络所必需的，而 NumPy 作为通用科学计算库无法直接满足这些需求。

# 二、代码框架

```python
import torch
import torch.nn as nn
import torch.optim as optim
# 第一部分 流水线
model = nn.Sequential(
    nn.Linear(5, 10),
    nn.ReLU(),
    nn.Linear(10, 2)
)
# 第二部分 算出损失
# 计算损失函数
criterion = nn.MSELoss()

# 第三部分 学习率 ，Adam优化
# 进行什么样的优化
optimizer = optim.Adam(model.parameters(), lr=0.01)

# 第四部分
# 1 生成训练样本
inputs = torch.randn(1, 5)
# 2 生成训练标签
labels = torch.randn(1, 2)

# 这个是重点  五步骤
# 1.清空优化器中的存的训练的偏导数的值
optimizer.zero_grad()
# 2.向前传播
outputs = model(inputs)
# 3.计算误差
loss = criterion(outputs, labels)
print(f"当前 Loss 值: {loss.item()}")
# 4.向后传播
loss.backward()
# 5.调整权重值
optimizer.step()

```
